### VPN: Virtual Private Network

- 仮想の専用回線を構築
  - => 暗号化されたセキュアな通信
- 機能
  - トンネリング
  - カプセル化
    - **別のプロトコルのデータとして包まれて送受信**
  - 暗号化
  - 認証
- 種類
  - IP-VPN
    - **通信事業者が独自に保有**する閉域ネットワーク
    - インターネット VPN より安全
      - 第三者は接続できない
    - 暗号化はあまり必要ない
      - => 高速化のためにしない傾向にもある
  - インターネット VPN
    - 一般の回線上に VPN トンネルを仮想的に構築
    - 安価で導入しやすい
    - 暗号化必須
- 認証
  - 3要素
    - 知識
    - 所有
    - 生体
  - PKI: 公開鍵基盤
    - 公開鍵暗号方式を利用して**個人や組織の信頼を確保するための社会きばん**
    - CA に証明書を発行してもらう

## 2

- Emotet
  - アクセスされるたびにコードが変わる
    - => シグネチャーベースのスキャンでは検知できない
  - スキャンされることを検知して動作を停止させる
    - => 振る舞い検知でも防ぐことが難しい
  - Emotet それ自体に不正なコードはほとんどない
  - **ローダー（ダウンローダー）のツール群**
    - **本体には不正な機能がない！**
    - マクロ経由で侵入
  - ほぼ壊滅？
    - C&C サーバーインフラが停止した？
- PPAP:
  - 略
    - Password 付き Zip
    - Password 送る
    - Angoka Protocol
  - **パスワードをかけて暗号化されたファイルはセキュリティスキャンできない**
  - **PPAP は送付先にセキュリティリスクを与える行為**でしかない
    - すぐやめよう
    - そもそも総当たり攻撃で必ず復元できるので漏洩防止にならない
    - TLS 暗号化のみでほぼ十分
